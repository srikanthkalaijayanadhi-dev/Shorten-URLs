📢 Ad Placement Control

🌍 All Pages — Global Ad Slots

These ads appear on every page (Home, Dashboard) via the shared ad loader. Each slot has its own code & toggle.

🔛 Enable Global Ads (All Pages)
Master switch — disabling this hides all global ads on every page.
🧩 Global Header Script
Injected into <head> on every page (Monetag global, AdSense init, etc.)

💡 This fires on index.html, dashboard.html, and redirect.html.

📰 Top Banner Ad
Displayed at the top of every page (leaderboard 728×90 or responsive).

Injected into .ad-slot-top on all pages.

🪧 Mid-Article / Content Banner
Displayed inside the AI Content article on the redirect page.

Injected into .ad-slot-mid on the redirect page content.

🗂️ Sidebar Ad (300×250)
Displayed in the dashboard sidebar panel.

Injected into .ad-slot-sidebar on all pages (usually 300×250 or 300×600).

🔲 Global Square Ad
A 300×250 square ad that appears on Home, Dashboard, and AI Content pages.

Injected into .ad-slot-square on all pages.

📰 Bottom Banner Ad
Displayed at the bottom of every page above the footer.

Injected into .ad-slot-bottom on all pages.

💥 Global Pop-up / Push Ad
Fires on all pages when they load (Monetag push, pop-under, etc.)

⚠️ This script is injected into <head> on every page.

📌 Sticky Bottom Banner
Stays anchored to the bottom of the screen on all pages.

💡 This creates a persistent banner at the bottom of the viewport.

🔗 Redirect Page — Ad Slots

These ads appear on the redirect/countdown page only.

🌐 Redirect Page Ad Settings

Enable Ads on Redirect Page
When disabled, all ad slots on the redirect page are hidden.

📰 Banner Ad Slots (Top & Bottom)

Show Banner Ads
Displayed above and below the main content on the redirect page.
Banner slot → full-width strip (728×90 or responsive)

💡 This code will be injected into the top & bottom banner ad slots on the redirect page.

🔲 Square Ad Slot (Countdown Box – 300×250)

Show Square / Box Ad
Displayed inside the countdown card while the timer runs.
Square slot → 300×250 box inside countdown card

💡 This code will be injected inside the countdown box on the redirect page.

⏲️ Timer Area Banner Ad (Top & Bottom of Ring)

Show Timer Ads
Displayed immediately above and below the circular timer ring.
Timer Slot → Banner surrounding the countdown circle

💡 This code will be injected above and below the timer circle on the redirect page.

💥 Pop-up / Interstitial Ad

Enable Pop-up Ad on Link Access
Fires an ad script when a user first opens the redirect page.

⚠️ Use responsibly — excessive pop-ups degrade user experience.

🧩 Header Script (injected into <head>)

Enable Header Script on Redirect Page
Injects your script into the <head> of the redirect page — ideal for Monetag, AdSense global scripts, etc.
This script is injected inside <head> before the page renders

💡 The script will be appended to <head> on the redirect page every time a visitor opens a shortened link.

📊 Multi-Page Ad Flow

Configure how many ad pages visitors see before getting the link. Each page has its own timer & ad code. Changes auto-apply to all links.

📄 Page 1 (15s) → 🔗 Link

ℹ️ After the last page timer ends, visitors see the "Get Link" button. Max recommended: 5 pages.
